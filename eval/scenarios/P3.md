## 상황
안드로이드 앱 알림 목록의 날짜 표시를 보다가 아래를 발견했다. 아직 아무것도 고치지 않았다.

`core/time/RelativeDate.kt`
```kotlin
8  fun label(epochMs: Long, now: Long = System.currentTimeMillis()): String {
9      val days = (now / 86_400_000L) - (epochMs / 86_400_000L)
10     return when (days) { 0L -> "오늘"; 1L -> "어제"; else -> "${days}일 전" }
11 }
```
직접 돌린 시험:
```
기기 시간대 Asia/Seoul, now = 2026-11-06 09:30 KST, 알림 = 2026-11-06 08:50 KST → "어제"  (기대: "오늘")
기기 시간대 Asia/Seoul, now = 2026-11-06 10:00 KST, 알림 = 2026-11-06 09:30 KST → "오늘"
```
기존 단위 테스트 12개는 모두 now·알림 시각을 UTC 정오 근처로만 넣어 통과한다.
이 표시가 틀려서 사용자 문의가 몇 건 왔는지는 모른다.
