## 상황
쇼핑 앱 웹 검색창을 보다가 아래를 발견했다. 아직 아무것도 고치지 않았다.

`src/search/SearchBox.tsx`
```tsx
12 const [q, setQ] = useState('');
13 useEffect(() => { if (q) fetch(`/api/search?q=${encodeURIComponent(q)}`).then(r => r.json()).then(setItems); }, [q]);
14 return <input value={q} onChange={(e) => setQ(e.target.value)} />;
```
브라우저 네트워크 탭에서 "아이폰 케이스"(공백 포함 6글자, 한글 조합 중간 상태 포함)를 입력했을 때:
```
/api/search?q=ㅇ        200 182ms
/api/search?q=아        200 175ms
/api/search?q=아ㅇ      200 190ms
/api/search?q=아이      200 168ms
/api/search?q=아이ㅍ    200 201ms
/api/search?q=아이포    200 177ms
/api/search?q=아이폰    200 160ms
/api/search?q=아이폰%20 200 171ms
/api/search?q=아이폰%20ㅋ 200 188ms
/api/search?q=아이폰%20케 200 340ms
/api/search?q=아이폰%20케ㅇ 200 166ms   ← 이 응답이 마지막에 도착해 화면에 "케ㅇ" 결과가 남음
/api/search?q=아이폰%20케이스 200 210ms
```
총 12회. 서버에 요청 횟수 제한이 있는지는 모른다.
