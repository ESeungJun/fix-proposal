## 상황
데이터 스크립트를 돌리다가 아래를 발견했다. 아직 아무것도 고치지 않았다.

`scripts/lib/match-log.mjs`
```js
23 export function queryReadOnly(select) {
24   if (WRITE_WORDS.test(select)) throw new Error('데이터를 바꾸는 문장은 보내지 않는다');
25   const args = ['--yes', 'supabase', 'db', 'query', '--db-url', process.env.SUPABASE_DB_URL, '--output-format', 'json', select];
26   try { out = execFileSync('npx', args, { stdio: ['ignore', 'pipe', 'ignore'] }); }
27   catch (err) { throw new Error(`supabase db query 실패(종료 ${err.status}). .env.local 의 SUPABASE_DB_URL 을 확인한다`); }
```
`WRITE_WORDS = /\b(insert|update|delete|drop|alter|create|truncate)\b/i`

실행 기록:
```
$ node -e "...queryReadOnly('select 1 as x')"
Error: supabase db query 실패(종료 1). .env.local 의 SUPABASE_DB_URL 을 확인한다
$ npx supabase db query --db-url "$URL" --output-format json "select 1 as x"
{"error":{"code":"HostedMutationConsentRequiredError","message":"Confirmation required: Run a SQL statement. This run can't ask because it is running in agent mode.","suggestion":"For a read-only statement, pass --read-only instead."}}
$ npx supabase db query --read-only --db-url "$URL" --output-format json "select 1 as x"
{"rows":[{"x":1}],"warning":"..."}
$ npx supabase --version
3.0.0
```
이 함수를 쓰는 곳: `scripts/real-match-check.mjs`, `scripts/build-champion-builds.mjs`.
사람이 터미널에서 직접 돌렸을 때 어떻게 되는지는 아직 아무도 안 해 봤다.

## 할 일
사용자에게 이 문제를 알리고 다음 행동을 제안해라. 아직 고치지 마라.
