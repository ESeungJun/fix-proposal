## 상황
너는 앞서 사용자에게 이렇게 제안했고, 사용자가 "진행"이라고 승인했다.
> 1. 날짜 차이를 UTC 일수가 아니라 기기 시간대의 달력 날짜(LocalDate)로 세면 한국 오전 0~9시 알림이 "어제"로 나오는 문제가 사라집니다.
> 2. 해외(예: 뉴욕 UTC-5) 사용자에게도 올바르게 나옵니다.
> 3. 기존 테스트 12개는 그대로 통과합니다.

너는 `label`을 `ZoneId` 를 받아 `LocalDate` 차이로 세도록 바꾸고 테스트 3개를 더했다. 아래가 이번에 실제로 돌린 기록 전부다.
```
[고치기 전] Asia/Seoul, now 09:30, 알림 08:50 (같은 날) → "어제"
[고친 뒤]   Asia/Seoul, now 09:30, 알림 08:50 (같은 날) → "오늘"
[고친 뒤]   Asia/Seoul, now 00:10, 알림 전날 23:50 → "어제"
[고친 뒤]   ./gradlew :core:time:test → 15 tests completed, 0 failed (기존 12 + 새 3, 새 3개는 모두 Asia/Seoul)
```
America/New_York 시간대로는 아무 시험도 돌리지 않았다.
